# Week 3 – Python Practice Projects 🐍

This repository contains my Week 3 Python practice projects as a first-year Artificial Intelligence and Machine Learning (AIML) student. These projects focus on Python lists, tuples, strings, and basic problem-solving.

## 📂 Projects

### 1. Appending to a List

Practising how to add new elements to a list using Python's `append()` method.

**Concepts Practised:**

* Lists
* `append()` method
* Adding elements to a list

### 2. Palindrome Checker

Checks whether a given word or string reads the same forwards and backwards.

**Concepts Practised:**

* Strings
* String manipulation
* Conditional statements
* Comparisons

### 3. List Sorting

Sorts the elements of a list into ascending order using Python's built-in `sort()` method.

**Concepts Practised:**

* Lists
* `sort()` method
* Modifying lists in place
* Ordering elements

### 4. Counting an Element in a Tuple

Counts how many times a specified element appears in a tuple.

**Concepts Practised:**

* Tuples
* Element counting
* Python's `count()` method or loops, depending on the implementation

## 🛠️ Technologies Used

* Python 3
* VS Code or another Python-compatible editor

## ▶️ How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run a Python file using:

   ```bash
   python filename.py
   ```

   Replace `filename.py` with the name of the Python file you want to run.
